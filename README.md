ArtGallery – Digital Exhibition

ArtGallery is an Android application that allows users to explore digital art exhibitions, including Paintings, Sculptures, and Photography.

Features

- Exhibition Categories: Browse different types of artwork.
- Artwork Details: View the artwork image, artist name, title, and short description.
- View Artwork: Open a separate screen to see the artwork in detail.
- Favorites: Add artworks to favorites and receive a notification displaying the artwork title.
- Lifecycle Management: Demonstrate Activity and Fragment lifecycle callbacks through Logcat.

Technologies Used

- Android Studio
- Kotlin
- Activities and Fragments
- Views and Intents
- Android Notifications

How It Works

1. Select an exhibition category from the main screen.
2. Explore the artwork and its basic details.
3. Tap View Artwork to see the complete description and artist information.
4. Tap Add to Favorites to receive a notification containing the artwork title.
